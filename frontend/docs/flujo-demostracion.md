# Guion de demostración — cinco minutos

1. Ejecutar las pruebas unitarias de fixtures internos; este flujo no está disponible en la aplicación.
2. Iniciar análisis y mostrar la captura activa.
3. Explicar que la parte superior pertenece al modelo multimodal de tres clases.
4. Recorrer vida/escudo, inventario, audio y mapa como modelos independientes.
5. Mostrar los seis frames en orden y ampliar uno sin abandonar el dashboard.
6. Esperar una actualización de alertas y recomendaciones.
7. Pausar y reanudar para mostrar los controles.
8. Cambiar visualmente a API y regresar a demo si todavía no hay backend.
9. Reiniciar la sesión y dejar visibles el visor, KPIs y estados.
